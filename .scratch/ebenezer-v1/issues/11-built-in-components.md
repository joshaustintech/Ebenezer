# Built-in components

Type: grilling
Status: resolved
Blocked by:

## Question

Do the Liquid fork, the CommonMark engine and the Pagefind port ship as separate components (gems, spin packages or repos), or bundled into Ebenezer?

## Answer

Decided by the user: **all three are built-ins, bundled into Ebenezer's source tree and binary, not separate components.** See [ADR 0004](../../../docs/adr/0004-components-are-built-ins.md).
