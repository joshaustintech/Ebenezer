# CommonMark conformance scope

Type: grilling
Status: open
Blocked by:

## Question

What does "1:1 CommonMark compliant" commit the in-house engine to?
- Which spec version is pinned (0.31.2 is current), and is passing 100% of that version's spec.txt examples the bar?
- Is the HTML output byte-identical to the reference renderer (cmark)?
- Are any extensions in v1, such as GFM tables, strikethrough, task lists, autolinks or footnotes? Docs portals will want tables.
- Are heading IDs, smart punctuation and syntax-highlighting hooks part of the engine or a later stage?
- How does Ebenezer track new spec versions?
